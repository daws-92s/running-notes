shell vs command
=================
both executes commands on remote host
1. if we use shell we get full access to the server means its env and variables

2. command module will not have any access to server env and variables, it will just execute the command. redirections and pipes will not work here in command module

for simple commands use command module, for complex commands with redirections and pipes and if we need env then use shell module
