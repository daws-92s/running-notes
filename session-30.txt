create infra with ansible 
=========================
-> ansible can create infra
-> ansible can't update the infra
-> ansible can't delete the infra

declarative way of creating infra
-> whatever we write we need it -> terraform can do this

terraform has something called state. state is like memory. It can understand what it had creating earlier, what user wants now. it can compare and take the action

terraform/IaaC advantages
===================
1. version control with infra as a code
2. declarative way of creating infra, provided we use right syntax
3. consistent infra -> lower env are ignored than PROD. working in DEV not working in PROD
4. Reusable infra -> modules. we can use same code to create infra across different projects
5. Dependency management -> terraform can identify dependency between the resources
6. CRUD -> create read update delete the infra
7. inventory management -> we can read the terraform resources and understand what we are using
