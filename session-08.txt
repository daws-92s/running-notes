5. Traffic monitoring and content restriction

HTTP status codes
=================
computer only cares about numbers, humans cant remember numbers

HTTP status codes
=================
2XX -> success
	201 -> created
	200 -> OK, you got response
	204 -> No content, info deleted
	
4XX -> client side error
	400 -> bad request
	401 -> wrong credentials
	403 -> no authorization
	404 -> not found
	
5XX -> server side error
	500 -> Internal server error
	501 -> Not implemented
	502 -> Bad gateway. frontend is not able to connect backend
	503 -> service unavailable
	504 -> backend is not responding on time

1XX -> Information
3XX -> Redirection
