Linux directories heirarchy
===========================
afs -> andrew file system, to share the files between multiple hosting using network as if they are local files
/bin -> all commands we are using are here..
/boot -> it has files required to boot linux server. vmlinuz-* is related to kernel, initramfs -> ram. grub2 is the boot loader
/dev -> devices. all the devices including disks, keyboard, mouse are here

/etc -> extra configuration.. /etc/users, /etc/group, /etc/nginx, /etc/yum.repos.d, /etc/systemd, /etc/sshd, /etc/sudoers, /etc/passwd

/home -> this is where every user get their personal space /home/ec2-user /home/ramesh users home directory

/lib -> system libraries

/media -> in linux desktop environments, removable disks like USB, cd/dvd, hd will be automatically mounted in desktop environments

/mnt -> if we add extra disk, we can manually mount the disk here...

/opt -> optional. if we download and install third party softwares, we choose this directory

/proc -> kernel uses this directory to track process instance ID's
		/proc/cpuinfo
		/proc/meminfo
		
/root > root user home directory

/run -> programs running inside server keeps track of their process here

/sbin -> system administration commands are here

/srv -> no one is using now, actually intended to keep the shared data for the services.. service files /usr/share/nginx/html.. 

/swap -> virtual ram..if it is used it means ram is full

/tmp -> temporary files..

/var -> variable data, logs
