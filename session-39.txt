IAM Role
=========
access-key, secret-key

IAM -> Identity access management

User -> human user, they have username and password. or access-key and secret-key for programmatic access
Group -> a group of users
Role -> non human user. like services in AWS. a service in AWS wants to do CRUD on other resources we create role to that service. third party users called as federated users they can also assume this role.

Policy -> a list of permissions we can perform on resources

authentication and authorisation

authentication -> who you are
authorisation -> what you are

nouns and verbs
nouns -> resources -> EC2, S3, ALB, EBS, R53, CDN, etc...
verbs -> actions on resources -> CRUD

Policy -> a list of permissions

- can create ec2 (what action on what resource)
- can read s3
- can read alb

ARN -> Amazon resource name -> a unique name accross  1 AWS account or all AWS accounts

arn:aws:iam::aws:policy/AdministratorAccess
