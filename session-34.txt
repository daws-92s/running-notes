tfvars approach
===========
tfvars -> setup the values to terraform variables, it can override default values

pros
====
same code
clear state isolation between environments

cons
====
1. if you forget reconfigure, you may be in prod assuming that you are in dev
2. while apply or destroy by mistake if you load diff vars, then problems comes
3. changes done for one env, defnitely effects other environment. we should be very careful. a single change also we should think other env too..
