Ansible Roles - V2
=============
Dont store passwords as plain text
Organise playbooks

Roles is a proper directory structure of creating and managing playbooks. We can breakdown playbooks into multiple components like

by default ansible loads main.yaml

roles
	catalogue
		tasks/
		- main.yaml -> all tasks will be here
		vars/
		- main.yaml -> all role related variables are here
		defaults/
		- main.yaml -> low priority variables are here
		templates/
		- *.j2 -> jinja2 templates are here
		files/
		handlers/         #
        - main.yml      #  <-- handlers file
		meta/
		- *.yaml -> all dependencies are here
		library/          # roles can also include custom modules
        module_utils/     # roles can also include custom module_utils
        lookup_plugins/   # or other types of plugins, like lookup in this case
		

module/task vs plugin
module -> runs in target server
plugin -> runs on ansible controller for external tasks like fetching secrets, etc..
